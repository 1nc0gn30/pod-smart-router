Frequently Asked Questions

Why use both Printify and Gelato?

Printify offers rock-bottom base costs for US domestic volume through their US print provider network, while Gelato provides 32 localized international production hubs across Europe, Canada, and Australia that eliminate steep cross-border tariffs and customs delays.

Is the Production API Dispatch Payload unlocked?

Yes. All Printify Order API v1 and Gelato Order API v2 JSON dispatch schemas are 100% unlocked by default for direct copy or JSON download.

Can I execute this directly from Python or the terminal?

Yes. The repository includes an executable CLI (bin/pod-smart-router), an Antigravity MCP stdio server, and a high-performance HTTP daemon on port 8117.
